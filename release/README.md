# CloverMoss Launcher 开发版 0.1.0

这是 CloverMoss Launcher 的第一条公告。它来自仓库的 `release/README.md`，
启动器会把它渲染在首页与「公告」页。

## 现在可以用

- **环境体检**：系统、Metal/CUDA、内存、磁盘、Python、git 与网络，一次看清；
  还会按内存给出推荐档位（你这台 16 GB 的 M3 推荐 768² + 8 步 DMD）。
- **实例管理**：按 `OpenMOSS/MOSS-Image` 的分支与 commit 安装多个版本，
  每个实例固定 commit、互不影响；`main` HEAD 标记为稳定版。
- **运行时**：默认共享 Python 环境，可一键转为独立；依赖安装会实时显示日志。
- **模型与适配器**：官方权重、社区 int8/int4、8 步 DMD 的统一目录；
  下载走 HF 兼容缓存，支持断点与镜像，官方代码可直接命中。
- **三窗口**：启动器负责启动与监视；创作窗口负责 JSON/画布；终端窗口看 stdout/stderr。
- **启动条**：固定在首页底部、固定宽度居中；Case、后端、实例、设备、档位、高级、启动；运行后变成停止/终端/打开界面，并在上方插入一条新的启动条。
- **运行栈**：运行中的 Case 收在下方，可折叠、按名称或启动时间排序；同设备默认排队。
- **OOBE**：没有可启动实例时默认出现，检查实例/运行时/模型三行，可本次跳过。
- **创作台**：写 Prompt、选尺寸/步数/CFG/Seed；右侧画布可以框选人物、物体和文字区域。
- **布局标注**：按官方 layout JSON 规则编译成 `abs_centralized + yxyx`，一键插入 Prompt；
  编译器与官方 `compile_prompt.py` 对拍一致。
- **画廊**：启动器侧栏的全局工具，自动读取输出目录，也可以添加任意本地文件夹；分页加载，支持详情、元数据与“用作布局底图”。
- **背景**：内置 16:9 深灰占位图，设置里可换任意本地图片；背景铺满首页及其他页面与终端。
- **训练**：侧栏训练页可部署 KohakuMossTrainer、按 commit 建版本、装环境；独立 Kohaku Trainer 窗口负责配置/命令预览；CUDA 主机可启动训练，step/loss 进共享终端；SSH host 可先保存，连接执行下一阶段。
- **通知中心**：右上角抽屉，默认打开；上半是仓库公告，下半是实例/安装/下载/任务等应用内通知。
- **诊断**：OOM、缺包、网络、缺权重等会变成带解决方案的卡片；同一错误不会反复弹窗。
- **终端**：独立窗口，左侧 Cases，右侧 xterm，支持 stdin 与停止。
- **界面**：中性深灰亚克力，无绿色、无深蓝底；标题栏居中应用名 + dev/release + 版本；侧栏无 Logo。

## 已知限制

- **50 步很慢**：MOSS-Image 是 5B DiT + 8.4B 文本编码器。16 GB 的 Mac 上，
  1024²/50 步大约需要半小时；建议先用 **8 步 DMD + 768²**。
- **首次下载较大**：bf16 全量约 27 GB；16 GB 机器建议用社区 int8/int4 包。
- **Windows 未实机验证**：当前只在 macOS arm64 上实测。
- **尚未内置推理引擎**：运行官方 Python；真实权重链路需在足够磁盘的机器上验收。

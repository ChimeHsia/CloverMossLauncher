# 路线图

> V1 是**启动器**，不是推理引擎。引擎顺延到 V2（见 [ADR-0003](decisions/0003-launcher-first.md)）。
> 每个里程碑都有可测验收，不达标不进入下一阶段。估算按 1 名全职工程师。
>
> **进度（2026-10-19）**：M0–M3 已完成基础实现，**UI v0.2** 已落地
> （亚克力/折叠侧栏/通知中心/画廊/创作台与 layout 标注器），**M4 运行/进度/诊断基础完成**。
> 实测证据与已知差异见 [status.md](status.md)。

## M1 · 壳与环境报告（已完成 2026-10-19）

**范围**

- `electron-vite` 工程、单窗口 1180×760（最小 960×640）、深浅色、侧栏路由；
- IPC 契约 + zod 校验 + preload 白名单；
- 环境探测：OS/CPU/内存/磁盘、Metal/CUDA、Python/git/uv、网络/镜像；
- 首页：公告卡（读 `release/`）、环境报告、推荐档位、最近实例占位；
- 设置页骨架（网络、存储、外观）。

**验收**

- ✅ 1180×760 窗口（最小 960×640）、深浅色、折叠侧栏、类型化 IPC + zod；
- ✅ 环境报告在 macOS arm64 上实测（8 项检查、推荐档位）；
- ✅ 公告读取本地/远程 manifest、缓存与已读；
- ⏳ Windows/Intel 字段验证、断网缓存展示留到 M6 设备矩阵；
- ✅ 渲染进程无 Node 能力（sandbox + 最小 preload + CSP）。

## M2 · 实例与运行时（基本完成 2026-10-19）

**范围**

- bare 镜像克隆 / fetch / 分支与提交列表；
- worktree 创建、pin、回滚、删除、dirty 检测；
- 运行时发现、托管 Python、uv/pip 安装、锁哈希、共享/独立、修复；
- 新建实例向导（版本 → 运行时 → 模型 → 启动配置）；
- 实例详情：概览 / 版本 / 依赖。

**验收**

- ✅ 两个不同 commit 的实例共用同一 runtime `py3135-a02c6928`，worktree 互不影响；
- ✅ 新建向导（分支 → 提交 → 名称 → 共享/独立）；
- ✅ 依赖安装实测：43 包 / 785 MB，torch 2.14.1 + MPS 可用；
- ⏳ 托管 Python（python-build-standalone）未接，当前用系统 Python；
- ⏳ 实例更新/回滚有 IPC 与函数，但 UI 只做了删除/转独立；
- ⏳ 第 3 个实例、回滚耗时未做正式验收。

## M3 · 模型与适配器（基础完成 2026-10-19）

**范围**

- HF 兼容缓存下载器（清单、Range 续传、并发、哈希、镜像、暂停/恢复）；
- 内容寻址的适配器存储；
- 模型目录（`release/models.json`）、详情、校验、删除保护；
- 适配器导入（拖拽/仓库/链接）、启用/禁用、强度、冲突提示；
- 下载队列 UI（全局 + 单文件）、磁盘保护。

**验收**

- ✅ HF 兼容缓存（blobs/snapshots/refs）实测：12.5 MB 测试仓库、10 文件；
- ✅ `transformers` 在 `HF_HUB_OFFLINE=1` 下可解析下载结果；
- ✅ Range 续传、LFS sha256 校验、暂停/继续、磁盘保护已实现；
- ⏳ 杀进程后续传、镜像切换、27 GB 大文件未做正式验收（本机仅剩 15 GB）；
- ⏳ 适配器启用/禁用、强度、实例绑定 UI 未接；
- ⏳ 下载队列仅内存，重启丢失。

## M4 · 运行、进度与诊断（基础完成 2026-10-19）

**范围**

- Supervisor：进程组、readiness、stdin、优雅停止、崩溃循环保护；
- 薄 runner（Python）与 NDJSON 协议；
- 解析管线：ANSI、`\r` 帧、tqdm、HF 下载、错误规则；
- 运行页（进度/阶段/控制台/stdin）、诊断页（卡片/筛选/导出）；
- 画廊：PNG + 元数据 + 复现。

**验收**

- ✅ tqdm `s/it`、HF 下载条、ANSI/`\r` 分帧已实现；样例解析正确；
- ✅ signature 去重 + 5 min ≤ 3 条 toast 预算；
- ✅ 内置 rules + `release/rules.json`，E_OOM/E_MODULE/E_NET/E_MODEL 等可命中；
- ✅ 取消实测：运行中 → `canceled`；
- ✅ 运行页/诊断页/控制台/stdin/任务历史；
- ⏳ 真实 27 GB 权重生成未验收；Gradio 基础适配未实测；DMD 采样器未实现；
- ⏳ 日志 5k 行/s 压测未做。

## M5 · Gradio、WebUI 与更新（当前，3 周）

**范围**

- Gradio 适配器（启动、端口、readiness、内嵌/外开、关闭）；
- 启动器 Web 模式（Fastify + SSE + token + 二维码 + 局域网开关）；
- 更新检查：manifest 多镜像、ETag、签名、通道、min_supported；
- 公告渲染与已读/不再显示；
- 自动更新下载与重启安装（macOS 先行）。

**验收**

- 同一前端在桌面与浏览器行为一致（除原生文件对话框）；
- 手机扫码可看队列与画廊；
- 篡改 manifest 后签名校验失败并拒绝更新；
- 更新下载可暂停/续传，安装后版本号正确。

## M6 · 打包与 Beta（2 周）

**范围**

- macOS 签名、公证、dmg/zip；
- Windows NSIS（长路径、Defender 说明、`py` 启动器）；
- 崩溃恢复、日志轮转、诊断包脱敏；
- 首次运行引导与文案打磨；
- 真实设备矩阵测试（M1/M3/M4、16/32/64 GB）。

**验收**

- 干净 Mac 上从下载到出第一张图 ≤ 30 min（含权重）；
- 16 GB M3 上 768²/8 步 ≤ 3 min；
- 无残留进程、无权限弹窗循环；
- Beta 渠道可回滚到 stable。

## V2 · 自研推理引擎（远期）

复用 [未来引擎架构](future-inference-engine.md)：MNN 为主、MPS 仅 oracle、MLX 条件触发。
启动器通过 `RuntimeAdapter` 接入，UI 与协议不变。

## V2+ · 训练器桥接

外部进程接入 KohakuMoss 或其它训练器（[ADR-0002](decisions/0002-trainer-backend.md)），
不在主仓库 vendor 训练代码。
